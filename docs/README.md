# Документация mailadmin

С чего начать, если проект попал к вам впервые:

1. **[Архитектура](architecture.md)** — что это, общая схема всей системы, из чего состоит, где какие данные.
2. **[Процессы](processes/README.md)** — блок-схема каждого процесса: от входа в почту до переноса ящиков.
3. **[Разработка](development.md)** — как поднять у себя, тесты, как добавлять функции, соглашения, выкладка.
4. **[Эксплуатация](operations.md)** — установка, обновление, порты, расписание, куда смотреть при сбое.
5. **[Подводные камни](gotchas.md)** — на чём уже спотыкались; прочитать до правок почтового ядра.

Схемы нарисованы в [Mermaid](https://mermaid.js.org/): GitHub показывает их прямо в файлах,
в редакторе нужен просмотр Markdown с поддержкой Mermaid.
