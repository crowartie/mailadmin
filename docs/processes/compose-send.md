# Написание письма, черновики, отправка с отменой, отложенная отправка

Отправка не уходит сразу: несколько секунд письмо ждёт в браузере, и «Отменить» возвращает
его в редактор. Перед этим сохраняется страховочный черновик. Большие файлы уходят ссылкой
на своё облако. Ошибка SMTP объясняется словами, а опубликованные для письма файлы откатываются.

```mermaid
flowchart TD
    S["Ответить, Переслать, Написать, Как новое, Черновик"] --> F["useCompose: получатели, тема, цитата, подпись, вложения исходного"]
    F --> ED["Окно письма: автосохранение черновика раз в 30 с"]
    ED -->|Закрыть| DR["Черновик сохранён"]
    ED -->|Удалить| DEL["Черновик удалён"]
    ED -->|Отправить| WHEN{"Отправить позже?"}
    WHEN -->|да| NOW
    WHEN --> UNDO{"Окно отмены больше 0 с?"}
    UNDO -->|нет| NOW["POST /mail/api/send"]
    UNDO -->|да| SAFE["Страховочный черновик"] --> CD["Отсчёт с кнопкой «Отменить»"]
    CD -->|Отменить| ED
    CD -->|время вышло или ушли со страницы| NOW

    NOW --> SZ{"Размер с вложениями в пределе сервера? облачные не считаются"}
    SZ -->|нет| E413["«Письмо больше N МБ» — предложить облако"]
    SZ --> BLD["MailBuilder: от кого можно, Message-ID"]
    BLD --> CL["Файлы с галочкой «ссылкой» → облако: антивирус, квота, контрольная сумма"]
    CL --> KEEP["Вложения исходного письма; большие при отправке → облако"]
    KEEP -->|исходное письмо переложили| E409["409, вложения исходного снять"]
    KEEP --> HTML["Блок ссылок на файлы, картинки data: → вложения cid, текстовая версия"]
    HTML --> SCH{"Отложенная отправка?"}
    SCH -->|да| OBX["Файл .eml и строка webmail_outbox; черновик удалён"]
    SCH -->|нет| SMTP["SMTP: свой логин через 587; общий ящик или вход администратора через 25"]
    SMTP -->|ошибка| MAP["Перевод ошибки: нет адреса, велико, нет прав, нет связи, занят"]
    MAP --> RB["Опубликованные для письма файлы удалить"]
    SMTP -->|принято| TIDY["Копия в «Отправленные», исходному — «отвечено», черновик удалить, адресаты в историю"]
    TIDY -->|копия не сохранилась| RET["Файл и строка webmail_sent_retry, задача досохранит"]
    TIDY --> REM{"Напомнить, если не ответят?"}
    REM -->|да| RMD["webmail_reminders"]
```

## Код

Клиент: `mail/useCompose.js`, `Components/Mail/Compose.vue`, `Components/Mail/Editor.vue`.
Сервер: `Mail/Api/ComposeController` (`send`, `draft`, `openDraft`), `MailBuilder`
(`build`, `publishToCloud`, `keptAttachments`, `attachedMails`, `cloudBlockHtml`), `Outgoing`
(`send`, `deliver`, `smtpFailure`, `keepSentCopy`, `saveDraft`, `sendRaw`), `LocalFiles`,
задачи `MailOutbox`, `MailSentRetry`.

- **Черновик** сохраняется в «Черновики» с флагами `\Seen \Draft`, получает новый UID,
  старая версия удаляется. Если файлы не менялись, отправляется только текст, вложения
  сервер берёт из прошлой версии.
- **От чьего имени можно писать**: свой адрес, свои псевдонимы, общий ящик, на который выдано
  право «владелец». Остальное — 422.
- **Пересылка вложением** прикладывает исходные письма как `message/rfc822`.

## Письма в работе (вкладки)

Начатое письмо не закрывается, когда открывают другое, а сворачивается во вкладку внизу
окна («В работе»), как в Outlook. До пяти писем сразу (`MAX_TABS` в `useCompose`), Alt+1…5 —
переключиться, «+» — новое. Просмотренные письма сами во вкладки не попадают: это выделение в списке.
Но прочитанное письмо можно закрепить кнопкой «Держать под рукой» (значок булавки в панели письма,
пункт в меню строки и в «Ещё» на телефоне) — например, чтобы номер счёта был перед глазами, пока
пишешь ответ. Такая вкладка серая, «только чтение», закрывается без вопросов и занимает место в
тех же пяти.

```mermaid
flowchart TD
    N["Написать / Ответить / черновик"] --> ROOM{"Писем в работе меньше 5?"}
    ROOM -->|нет| LIM["«Открыто 5 писем — закройте одно»"]
    ROOM -->|да| TAB["Новая вкладка: compose = письмо, composeTabs += письмо"]
    TAB --> OPEN["Открыли другое письмо: compose = null, окно прячется (v-show), не размонтируется"]
    OPEN --> SAVE["active → false: сразу сохранить черновик"]
    SAVE --> BACK["Щелчок по вкладке / Alt+N: compose = эта вкладка, всё как было"]
    TAB --> X["Крестик: close() — черновик, внизу «Удалить», вкладка убрана"]
    TAB --> SEND["Отправить: вкладка убрана, дальше — обычная отправка"]
    RL["Перезагрузка страницы"] --> PH["Вкладки из localStorage (номера черновиков) — заглушки"]
    PH --> LOAD["Щелчок: openDraft, заглушка заменяется письмом; черновика нет — сообщение"]
    HOLD["«Держать под рукой» у прочитанного письма"] --> RT["Вкладка kind: read — папка и номер письма"]
    RT --> RO["Щелчок: письмо из другой папки — сначала перейти в его папку, потом открыть"]
    RO -->|"404"| GONE["Письма нет (перенесли, удалили) — вкладка убирается с сообщением"]
```

Удерживаемое письмо открывается в своей папке намеренно: действия над открытым письмом
(«Удалить», «В папку») уходят в текущую папку, и письмо из другой задело бы чужое с тем же
номером. В поиске по всем папкам переходить не нужно — там строки и открытое письмо знают свою папку.

Окно письма каждой вкладки смонтировано всё время (обёртка `.mread__cmp` с `v-show`: у
`Compose` два корня, и `v-show` на нём самом не действует). У каждого — своё автосохранение;
о теме, адресате и времени сохранения окно сообщает событием `meta`. Черновик, уже открытый
во вкладке, второй раз не открывается — вкладка выходит вперёд.
