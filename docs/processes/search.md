# Поиск

Строка поиска понимает операторы и превращается в IMAP SEARCH. Текст ищет полнотекстовый
индекс Dovecot (fts_xapian), имена файлов и признак вложения — разбор структуры писем.

```mermaid
flowchart TD
    Q["Строка поиска"] --> P["SearchQuery: от:, кому:, копия:, тема:, текст:, до:, после:, есть:, файл:"]
    P -->|плохая дата| E422["422 с объяснением"]
    P --> C["Критерии IMAP SEARCH; свободные слова → TEXT"]
    C --> W{"Где искать?"}
    W -->|в папке| F1["UID SORT с критериями"]
    W -->|везде| ALL["Папки по порядку: текущая, Входящие, Отправленные, свои, общие, Спам, Корзина — до 25"]
    ALL --> T["На папку 3 с, всего 12 с"]
    T --> F2["До 200 писем с папки, общий порядок по дате"]
    T -->|не успели или ошибка| SK["Список пропущенных папок — показываем человеку"]
    F1 --> FILE{"есть:вложение или файл:?"}
    F2 --> FILE
    FILE -->|да| BS["BODYSTRUCTURE, оставить письма с подходящими файлами"]
    FILE -->|нет| OUT["Страница результатов"]
    BS --> OUT
    F1 -->|ошибка| ERR{"Какая"}
    ERR -->|SERVERBUG: индекс дописывается| RETRY["Повтор через 1,5 с"]
    ERR -->|таймаут, индексация| BUSY["503 «поиск ещё готовится»"]
    ERR -->|BAD, синтаксис| INV["422 «уберите спецсимволы»"]
    ERR --> REC["Всегда: переподключение IMAP"]
```

## Код

`SearchQuery`, `MessageListing::list`, `MessageListing::searchEverywhere`, `ImapQuery::searchUids`,
`ImapQuery::keepWithFile`, `Structure::files`.

Полнотекстовый индекс отвечает только по From, To, Cc, Bcc, Subject, Message-ID и тексту.
По другим заголовкам поиск молча пуст — см. [подводные камни](../gotchas.md#dovecot).
