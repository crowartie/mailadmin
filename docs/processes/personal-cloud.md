# Облако сотрудника

Раздел «Облако» в веб-почте: у каждого ящика своя папка для файлов любого размера. Файлы лежат
в Nextcloud, у одной служебной учётки, в папке `<корень>/<адрес ящика>`; сотрудник в Nextcloud
не заходит, всё идёт через почту. Общего доступа между сотрудниками нет, наружу — публичная
ссылка на отдельный файл.

```mermaid
flowchart TD
    B["Браузер: путь относительно своей папки"] --> API["/mail/api/cloud/*"]
    API --> PP{"PersonalPath: нет «..», точек в начале, служебных знаков, глубина до 30"}
    PP -->|нарушение| E422["422, в облако ничего не уходит"]
    PP --> HOME["Папка сотрудника = корень + адрес ящика: строит только сервер"]
    HOME --> OP{"Действие"}
    OP -->|список| PF["PROPFIND Depth 1; всё вне папки сотрудника и скрытое отбрасывается"]
    OP -->|папка, переименование, перенос| MK["MKCOL, MOVE без перезаписи; учёт ссылок следует за путём"]
    OP -->|удалить| TR["MOVE в .Корзина, запись в webmail_cloud_trash, ссылки отозваны сразу"]
    OP -->|ссылка| SH["OCS share: только чтение, срок, по желанию пароль"]
    OP -->|скачать, смотреть| XA["X-Accel-Redirect /_nccloud/: файл отдаёт nginx из Nextcloud, с докачкой и перемоткой"]
    OP -->|к письму| AT["Ссылки на файлы → блок «К этому письму приложены ссылки»"]
```

## Загрузка частями с докачкой

```mermaid
flowchart TD
    F["Файл выбран или перетащен"] --> K{"Есть незаконченная загрузка этого файла? localStorage: имя, размер, дата"}
    K -->|да| ST["GET uploads/id: какие части уже в облаке"]
    K -->|нет| NEW["POST uploads: место есть? имя свободно? MKCOL папки загрузки в Nextcloud"]
    ST --> LOOP
    NEW --> LOOP["Части по 10 МБ: PUT uploads/id/N, сервер сверяет длину"]
    LOOP -->|нет связи, 5xx, неполная часть| WAIT["Ждать «online» или 2, 4, 8… до 30 с, повторить эту же часть"]
    WAIT --> LOOP
    LOOP -->|все части| FIN["POST finish: Nextcloud собирает файл MOVE .file"]
    FIN --> OK["Файл в папке, запись в «Недавние»"]
    LOOP -->|вкладку закрыли| LOST["При следующем входе: «Не догрузились… выберите снова» — продолжим с той же части"]
```

## Код и настройка

| Что | Где |
|---|---|
| Пути и изоляция | `app/Services/Cloud/PersonalPath.php`, тест `PersonalPathTest` |
| Работа с Nextcloud | `app/Services/Cloud/PersonalCloud.php`, тест `PersonalCloudTest` (имитация Nextcloud) |
| Учёт: ссылки, загрузки, корзина | `CloudLedger`, `DbCloudLedger`, таблицы `webmail_cloud_links`, `_uploads`, `_trash` |
| API | `Mail/Api/PersonalCloudController`, маршруты `/mail/api/cloud/*` |
| Страница | `/cloud` → `Pages/Mail/Cloud.vue`; очередь загрузки `resources/js/mail/cloudUpload.js` |
| В письме | кнопка «облако» в окне письма → `Components/Mail/CloudPicker.vue` |
| nginx | `deploy/nccloud-accel.sh` (вызывает `update.sh`): location `/_nccloud/` |
| Корзина по сроку | `cloud:purge-trash`, ежедневно 04:45 |

Включение: админка → «Настройки → Файлы и облако». Nextcloud подключается служебной учёткой
(лучше отдельная локальная, не из домена), затем переключатель «Облако сотрудников»: место
на сотрудника, срок ссылки по умолчанию, срок корзины, имя корневой папки.
