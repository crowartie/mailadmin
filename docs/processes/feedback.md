# Обращения сотрудников

Сотрудник пишет обращение прямо из почты (ошибка, пожелание, вопрос) — к нему автоматически
прикладывается, где он был и какие ошибки видел. Администратор отвечает в админке, ответ
уходит сотруднику письмом; ответ письмом подшивается обратно в обращение.

```mermaid
flowchart TD
    E["Сотрудник: «Сообщить о проблеме»"] --> DG["Диалог: вид, текст, снимок экрана до 8 МБ"]
    DG --> CTX["Контекст: адрес страницы, браузер, версия, последние 8 ошибок"]
    CTX --> ST["POST /mail/api/feedback, не больше 5 в час"]
    ST --> T["feedback_tickets и feedback_messages"]
    T --> NT["Оповещение администраторам: почта, Telegram"]
    NT --> ADM["Админка «Обращения»: статус, приоритет, дубль"]
    ADM --> RP{"Действие"}
    RP -->|ответ| M1["Письмо сотруднику: тема «Обращение №N»"]
    RP -->|уточнить| W["Статус «ждём ответа»"] --> M1
    RP -->|закрыть с решением| CL["Закрыто, текст решения — сотруднику"]
    M1 --> REPL["Сотрудник отвечает письмом"]
    REPL --> IMP["feedback:import каждую минуту: ящик feedback@"]
    IMP --> MT{"Есть ссылка на обращение и пишет автор?"}
    MT -->|нет, автоответ или чужой| SKIP["Пропустить"]
    MT -->|да| ADD["Сообщение в обращение, обращение снова открыто"]
    ADD --> ADM
    ST --> SEE["Сотрудник видит свои обращения в почте: /mail/feedback"]
```

## Код

Почта: `Mail/FeedbackController`, `Components/Mail/FeedbackDialog.vue`, `Pages/Mail/Feedback.vue`.
Админка: `FeedbackController` (`reply`, `close`, `reopen`, `update`). Письма — `FeedbackNotifier`,
приём ответов — задача `FeedbackImport`.
