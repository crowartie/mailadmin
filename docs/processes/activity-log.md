# Журнал действий сотрудников и страница «Активность»

Чтобы видеть, чем люди пользуются, где ждут и где спотыкаются, каждое осмысленное действие
в веб-почте пишется одной строкой. Записываются только тип действия и числа — ни тем,
ни адресов, ни текста поиска.

```mermaid
flowchart TD
    RQ["Запрос к /mail или /mail/api"] --> APP["Ответ отдан"]
    APP --> MW["RecordActivity: после ответа"]
    MW --> MAP{"ActivityMap::describe: это действие человека?"}
    MAP -->|фон: опрос, подсказки, чтение настроек| DROP["Не писать"]
    MAP -->|да| ROW
    APP -->|ответ 500 и выше| ERR["Писать всегда как «Ошибка сервера» с текстом исключения"] --> ROW
    ROW["webmail_activity: кто, когда, действие, роль папки, числа, мс, код, устройство, вход администратора"]

    UI["Браузер: открыл и закрыл окно письма, бросил, открыл меню"] --> TR["track.js: копит, раз в 15 с или при уходе — sendBeacon"]
    TR --> BE["POST /mail/api/activity: только известные имена, до 50 за раз"]
    BE --> ROW

    ROW --> PG["Админка «Активность»: сутки, неделя, месяц"]
    PG --> CMP["Сравнение с таким же периодом до этого"]
    PG --> TBL["По действиям, людям, устройствам, папкам; ошибки; ответы дольше 3 с"]
    ROW --> PR["activity:prune: старше 90 дней — прочь"]
```

## Код

`Middleware/RecordActivity`, `Services/Mail/ActivityMap` (правила и подписи, тест `ActivityMapTest`),
`resources/js/mail/track.js`, `Mail/Api/ActivityController`, в админке — `ActivityController` и
`Pages/Activity/Index.vue`, задача `ActivityPrune`.

Новое действие веб-почты надо добавить в `ActivityMap`, иначе журнал его не увидит.
