# Открытие письма, вложения, переписка

Письмо не скачивается целиком. По структуре (`BODYSTRUCTURE`) выбираются части с текстом,
скачиваются одним запросом, вложения показываются списком без загрузки, картинки из текста
тянет браузер по отдельным ссылкам с кэшем.

```mermaid
flowchart TD
    O["GET /mail/api/message/папка/uid"] --> SEEN{"Отмечать прочитанным?"}
    SEEN -->|peek или чужая общая папка без настройки| NO["Не отмечать"]
    SEEN -->|своя папка| YES["Отметить после чтения"]
    NO --> H
    YES --> H["Заголовки письма"]
    H -->|письма уже нет| E404["404 «Письмо не найдено»"]
    H --> BS["BODYSTRUCTURE, собственный разбор с цепочкой контейнеров"]
    BS --> BP["Части тела: text/plain и text/html одного письма; mixed глубже — вложенное письмо"]
    BP --> FP["Один FETCH только этих частей, раскодировка"]
    FP --> CID["cid: картинки → ссылки /attachment/N?inline=1; такие картинки не в списке вложений"]
    CID --> SAN["MailHtml::sanitize: стили письма в свою область, условные комментарии Word прочь, HTMLPurifier"]
    SAN --> BLK["Внешние картинки спрятаны в data-blocked-*, кнопка «Показать картинки»"]
    BLK --> ATT["Список вложений из структуры: имя, тип, размер, пустые части помечены"]
    ATT --> CLOUD["Ссылки на наше облако в тексте → карточки файлов"]
    CLOUD --> RES["Ответ клиенту; адрес отправителя — в историю адресов"]
    FP -->|не вышло| FULL["Запасной путь: полная загрузка письма библиотекой"]
    FULL --> SAN

    RES --> TH["Отдельный запрос: переписка"]
    TH --> IDX{"Папка есть в указателе переписок?"}
    IDX -->|да| MT["mail_threads: до 30 писем цепочки из всех папок"]
    IDX -->|нет| OR["Поиск по References, In-Reply-To, Message-ID в 12 папках"]
    OR -->|ссылок нет вовсе| SUBJ["По теме и собеседнику"]
```

## Код

`Mail/Api/MessageController` (`show`, `thread`, `attachment`, `attachmentPreview`, `attachmentsZip`,
`cloudZip`, `attachedMessage`, `raw`), `MessageBody`, `Structure`, `MailHtml`, `MailCss`,
`MailAttachments`, `OfficePdf`, `AttachedMessage`, `ThreadBuilder`, `ThreadIndex`,
`LocalFiles::cardsIn`; клиент — `Components/Mail/MessageView.vue`.

Указатель переписок заполняет задача `threads:sync --all` раз в 10 минут и каждое перемещение письма.
