# mailadmin — памятка для разработчика и ИИ-помощника

Веб-почта и админка на Laravel + Inertia + Vue 3 поверх iRedMail (Postfix, Dovecot, Amavis).
Вся документация — в [docs/](docs/README.md). Прежде чем менять код, прочитайте:

- [docs/architecture.md](docs/architecture.md) — общая схема системы и где что лежит;
- [docs/processes/](docs/processes/README.md) — блок-схема нужного процесса;
- [docs/gotchas.md](docs/gotchas.md) — на чём уже спотыкались (обязательно перед правками почтового ядра);
- [docs/development.md](docs/development.md) — запуск, тесты, как добавлять функции, соглашения.

Главные правила:

- Комментарии, тексты интерфейса и коммиты — по-русски; комментарий объясняет, почему код такой.
- Ошибки для пользователя — `MailException` с понятным текстом, а не текст библиотеки.
- Всё, что требует root, — только через `deploy/mailadmin-ctl` и `Ctl::run()`.
- Таблицы iRedMail (`vmail`) не менять по схеме.
- Новое действие веб-почты — в `ActivityMap`, иначе журнал действий его не увидит.
- В репозиторий не попадают пароли, ключи, внутренние адреса, имена сотрудников и их переписка.
- Перед коммитом: `git status --short | grep '^ D'` — ничего не удаляется по ошибке.
- Тесты: `php artisan test`; изменения клиента — `npm run build` и проверка в браузере.
