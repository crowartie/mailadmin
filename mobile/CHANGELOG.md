## Почта 1.2.7

- Календарь: правка «всей серии» из открытой встречи больше не переносит серию на её дату; «только эта встреча»
  сначала сохраняется отдельно и лишь потом убирается из серии; напоминание не появляется само у встреч без него;
  целодневные события не сдвигаются на день при другом часовом поясе; перенос пальцем откатывается при ошибке;
  календарь можно сменить у существующего события.
- Почта: в поиске «везде» действия над письмами из разных папок уходят каждое в свою папку; быстрый переход
  по папкам больше не показывает ложное «Нет связи»; окно «Отменить» не схлопывается другими сообщениями,
  а при уходе приложения в фон отложенные действия выполняются сразу.
- Письмо: вложения исходного письма при ответе не пропадают после автосохранения; файлы «ссылкой» ниже порога
  не теряют отметку; закрытие окна во время загрузки не обрывает её; «Отправить» во время загрузки файлов
  сработает, даже если окно закрыть; сеть с порталом входа больше не роняет приложение.
- Обновление: файл ставится только после успешной проверки; учитывается номер сборки.
- Облако: докачка ждёт связь до 10 минут, идущую загрузку можно отменить.
- Правила: оператор «соответствует шаблону»; форма закрывается только после сохранения на сервере.
- Контакты: поиск без мерцания устаревших результатов; фото с камеры не ложится на бок.
- «Мгновенно» и ПК: проверка почты легче для сервера и батареи; на ПК появились уведомления.
- Ctrl+F на ПК больше не закрывает недописанное письмо.
